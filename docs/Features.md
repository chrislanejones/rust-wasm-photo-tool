# Features

> Part of the [Image Horse](../README.md) docs. See also: [Architecture](Architecture.md) · [File Map](File-Map.md) · [Keyboard Shortcuts](Keyboard-Shortcuts.md) · [Getting Started](Getting-Started.md) · [Change Summary](Change-summary.md).

### Image Processing (Rust/WASM)

- **Clone Stamp** — Alt+Click source, paint to clone with adjustable size, hardness, opacity, spacing
- **Red Stamps** — REJECTED / APPROVED / DRAFT / CONFIDENTIAL / UNDER REVIEW presets; JS renders label to OffscreenCanvas, Rust scales to brush size via bilinear resize and composites with "Red Stamp" history entry
- **Edit group (Crop · Transform · Perspective · Color Picker · Layers · Canvas Size · Guides · Rulers and Grid)** — each is its own sub-tool with its own panel section and its own URL, split out of the single combined tool they used to share. **Crop**: interactive SVG overlay with rule-of-thirds guides and 8 draggable resize handles, committed through Rust. **Transform**: flip horizontal/vertical, rotate 90° CW/CCW. **Layers**: pick a layer, then move, scale or mask it. **Canvas Size**: grow or shrink the background canvas without resampling. **Guides**: draggable horizontal and vertical alignment lines
- **Select group** — six ways to pick pixels, one exclusive set (**Select** on the rail): Magic Wand (flood-fill a region within a color tolerance), Edge-aware (the same fill, stopped at the outline by an edge map), Magnetic Lasso (click anchors and the wire path-finds along the edges), Color Range (every pixel near the clicked color, anywhere in the image), and Rectangle and Ellipse marquees. The flood-fill, mask and delete are all Rust (`magic_wand_select` / `delete_selection`), with `Alt+A` select-all and `Alt+D` deselect. How a new selection meets the one you have is **Combine**, in the Review panel (`Alt+R`) rather than on this panel — it applies to every gesture and to placed objects, so it is not a Select-tool setting
- **Placement grid** — a nine-cell grid in the Text and Shapes panels drops the selected text or shape into that ninth of the canvas. It folds away under a header called **Placement** at the foot of the panel — a collapsed section is always named for what is inside it, never "Advanced". Rust centers the bounding box in the cell (`align_annotation`) as a single undo step
- **Text Shadow** — soft drop shadow on the text glyphs and/or the background box, in the Text panel below the color swatch: shared color / opacity / offset / blur, rendered in Rust (offset + box-blurred silhouette, tile grown to fit so Align sees it) and persisted with the edit
- **Security tab** — EXIF keep/strip moved out of Compress into Settings → Security as a saved preference (applies to every export path); GPS / capture-time / lens stays or goes by your choice
- **Responsive / snapped windows** — one shared `useBreakpoint` hook: below ~1000px the top bar goes icon-only, below ~900px the side panels float as overlay drawers (scrim, one at a time) instead of crushing the canvas, below ~600px the editor steps aside for a phone surface — upload, add and view the gallery, no editing — with a gear that opens Theme, Motion and Sync. Reduce Motion suppresses the layout slides
- **Keyboard accessibility** — Skip-to-canvas link, landmark roles + labels (toolbar / panels / canvas), accessible names on the tool buttons, and Escape-to-close + `role="dialog"` semantics on the modals; on top of the existing tool / number / Alt shortcuts
- **Resize & Compress** — one tile, one panel, read top to bottom: **Resize** (Method dropdown, width × height, Scale), then **Compress** (Quality), then a plain **Google PageSpeed** section. Resampling is fully in WASM with no canvas round-trip, and the photo lands on the exact size you type, canvas border or not. Quality has the same edited dot and reset as Scale; dragging it adds nothing to History, and Apply records one step. The button says **Apply**, or **Resize** once the size has moved. **Image weight** is the measured size of the file Apply would write, against Google's image limit for that many pixels (`pixels / 6 + 4 KB`, from Lighthouse's image-delivery audit), marked Pass or Over. **Than upload** says how much smaller or bigger that file is than the one you uploaded. The format row — WebP, JPEG, PNG, AVIF, with WebP first — is a preview of what the photo would weigh as each: Apply keeps the photo's own format, and the Export dialog opens on the one you picked. A re-save that would come out bigger than the stored file is refused with a toast instead of quietly doing nothing; a resize always writes
- **Adjustments** — Brightness, Contrast, Saturation, Shadows, Highlights, Blur and Sharpen as sliders (**Enhance → Adjustments**). The photo updates as you drag, and letting go is one undo step — there is no Apply button. The engine works every setting out from the photo as it was when the panel opened (`src/adjust.rs`), so changes never pile up or clip along the way and each slider's reset puts back exactly what was there. Every slider shows a dot when it has been moved, with a reset beside it; Reset puts them all back. Leave the panel or switch photos mid-change and the change is kept. **Levels** (Black point), **Resize** and **Canvas Size** (their Scale row) show the same dot and reset when they differ from this photo's starting point
- **PageSpeed budget (Beta: Settings › Beta)** — **Compress All** aims for each photo's own budget instead of a flat 200 KB: the limit Google's image audit actually uses, `bytes ≤ width × height / 6`, from `TARGET_BYTES_PER_PIXEL_AVIF = 2 * 1/12` in Lighthouse's `image-delivery-insight`, kept between 28 KB and 1 MB. Resize & Compress shows that limit as Image weight for everyone, switch or not. Compress All **never writes a file larger than the one it replaced**, also for everyone — the fix for a bug that re-encoded an already-small q60 JPEG up 11% and reported success. Worth knowing: **resizing smaller does not improve the ratio** (fewer pixels lowers the limit by the same factor as the file), so what fixes a dense photo is a lower quality or a next-gen format
- **Photo info, handled by the engine (Beta: Settings › Beta)** — camera info (EXIF and location) is read, stripped and kept by the Rust engine, checked byte for byte against the JavaScript way on every photo; if the two ever disagree you get the old result and the difference goes to Diagnostics
- **History forks (Beta: Settings › Beta)** — undo a few steps, edit, and the steps you undid are kept as a branch instead of thrown away. A **Time Machine** list under History shows them; click one to go back to it, and the timeline you left becomes a branch in turn. Branches live in memory only and share the undo budget, and they are the first thing dropped when it runs short (`?beta=history-forks`, ADR-086)
- **Levels** — black point, white point and midtones (**Enhance → Levels**), each with its own reset beside it. The photo updates as you drag: the preview works from a copy of the layer, recomputed through a 256-entry lookup table on every move, so moves never compound. Apply makes it one undo step; leave the panel without applying and the photo goes back (`src/levels.rs`). The histogram is pinned to the bottom of the panel, so Levels no longer draws a curve chart of its own
- **Presets** — twelve one-click looks (**Enhance → Presets**): Enhance, Vivid, Fade, Dark, Warm, Cool, Mono, Noir, Airy, Moody, Recover and Lift. Hover one and it previews on your own photo; click it and that is a single undo step. A preset is not a new filter — it is five numbers (brightness, contrast, saturation, shadows, highlights) run through filters the engine already had (`apply_stack` in `src/presets.rs`). The engine has no hue or temperature control, so Warm and Cool are saturation looks, not color temperature
- **Histogram** — live RGB / Luma scope in the Review panel, computed in Rust (`calculate_histogram`) straight from the composite buffer — no per-frame offscreen-canvas sampling. The same histogram is pinned to the bottom of the panel on **Enhance → Adjustments**, **Levels** and **Presets**, so it stays in view while you drag
- **Fast integer compositing** — all alpha blending (`blend_pixel`, `blend_over`) uses integer source-over math instead of per-pixel float `÷255.0`, verified identical to the old result within ±1
- **Color Picker** — its own sub-tool under **Edit → Color Picker**; hovering the canvas shows a floating 11×11 magnifier (sourced from Rust `get_pixel_region`); clicking picks the pixel color and sets it as both brush and text color
- **Blur Brush** — Box-blur with stroke-based region masking; configurable radius and intensity; its own sub-tool under **Create → Blur Brush**
- **Arrows & Diagram Shapes** — Anti-aliased arrows with arrowhead (single or double), plus **30 diagram shapes** — the flowchart symbols (terminator, data, document, multiple documents, predefined process, manual input and operation, preparation, database, internal storage, off-page connector, delay, display, stored data, merge, card, punched tape, summing junction), basic shapes (pentagon, octagon, cloud, callout, cross, cube, note) and block arrows (block, double, four-way, chevron, step) people use most in Lucidchart and draw.io. Each one strokes, fills, turns, goes sketchy and re-selects like any other shape; **Create → Arrows & Shapes**
- **Shapes** — Rectangles, circles, hand-drawn circles, lines, diamonds, **triangles** and **stars** rendered in WASM; a Sloppiness slider ramps the outline from firm to hand-drawn; the star's **Points** slider takes 3–12; every shape has a **rotate hook** under its edit box (Shift snaps to 15°, a line turns by its endpoints), stored as an angle beside the upright box so a turned shape stays crisp and keeps its fill; a **Corner Radius** slider rounds the rectangle, diamond, triangle and star (Figma's corner radius), and the small dots inside the edit box's corners do the same on the canvas — drag one to round every corner, **Shift**-drag to round only that corner (the slider then reads *Mixed*); the circle and the line have no corners to round; **Create → Shapes**, with Arrow and Pins as their own sub-tools beside it. **Corner radius** rounds the corners of a rectangle, diamond, triangle or star — a slider for all corners, or drag a corner dot on the edit box (Shift-drag rounds just that one). **Oval**: drag the oval handle on the left of a circle's edit box and the circle stretches to fill its box (kind 41); it fills, turns and goes hand-drawn like the rest
- **Fill** — every shape that encloses an area takes one: rectangle, circle, diamond, triangle, star, as **Solid**, **Gradient** or **Pixelate**. The line is the one shape without the section, because it has no interior. A polygon is clipped by its own outline rather than its bounding box — the corners a star's points miss stay empty — using the same vertex list the engine strokes, so the fill and the outline cannot disagree. Rotate a filled shape and the fill turns with it, gradient direction and pixelate grid included
- **Paint / Brush** — Freehand painting via WASM `paint_dab` + `paint_stroke_to`; configurable brush size, color, and opacity; **Create → Brush**, with Pen and Blur Brush as sibling sub-tools
- **Pen (Vector Paths)** — Photoshop-style Bézier pen (**Create → Pen**): click to drop corner anchors, click-drag to pull smooth curve handles, and grab any anchor or handle to reshape the path. Enter closes it, Esc finishes it open. An optional solid **background** fills the closed interior (Rust scanline polygon fill, under the stroke). Committed paths stay **re-editable** — click one to re-open its anchors/handles — and round-trip through history, photo-switch, reload, and cloud sync as a kind-7 `ShapeAnnotation` (cubic control sequence flattened with de Casteljau)
- **Perspective / Distort / Skew** — one four-corner quad with three drag rules (**Edit → Perspective**), and it works on the **vector objects the app draws**: click a square, a circle, a line, an arrow, a pin, a pen path or a piece of text and the corners are stored ON that object as fractions of its own box, applied at render time. So the warped thing is still an object — recolor it, move it, resize it, undo it, or re-select it and adjust the same quad, and the perspective comes along. With nothing picked the quad warps the pixels under it instead, which is destructive and says so. Apply / Reset / Cancel sit on the canvas under the box as well as in the panel; Esc cancels and takes the box off the canvas. Only the objects on the **active layer** are pickable, and switching layers drops the pick. The homography solve and the resampler are Rust (`src/perspective.rs`); the drag rules are TypeScript on purpose, because they run per `pointermove` and a worker round trip there is the banked-lag failure the brush arc spent five releases removing
- **Text** — Click-to-place text with a choice of typeface, size, weight and color. The font menu picks real fonts: Liberation Sans, Serif and Mono (SIL OFL 1.1), regular and bold, fetched as static files and handed to the engine at runtime (`register_font`), so committed text is drawn in the face you previewed. Up to 8 recent texts re-open the canvas text box at the last used position, restoring all text settings
- **Emoji Stamp** — Browser renders emoji to `OffscreenCanvas`, pixels sent to WASM `stamp_pixels()` for alpha compositing; **Create → Emoji**
- **Batch Crop** — one crop over a whole gallery, so every slide in a carousel lines up (**Batch → Crop**). Need a few to be different? Tick photos 4 and 6 in the gallery, or tick **Exception** on any photo in the canvas grid — every one of the twelve has its own — and switch to Exceptions: they get their own ratio, keep spot and width, and one button crops both groups: **Crop 8 to 1:1 · 2 to 4:5**. The bar under the grid counts the photos and the exceptions, and pages through a gallery bigger than the grid with ‹ ›. Every Batch tool has the same Main | Exceptions switch. Logo, Text, Rename and AI Rename run on the group that is showing. Then the crop itself, for carousels: 1:1, 4:5, 3:4, 4:3, 3:2, 16:9 or 9:16, a nine-cell grid for which part of each photo to keep, and an output width (1080px, 1440px, or keep each crop's own size) so every slide comes out the same shape and the same pixel size. The preview shows the crop frame: drag it to move, drag a corner to resize (the ratio stays locked), drag anywhere else on the photo to draw a new one, or use the arrow keys and + / −. Hold **Shift** while dragging to break the ratio; the free shape becomes a custom ratio that every photo is cropped to. When you let go, every other photo follows that frame, and their thumbnails (gallery strip and canvas grid) shade the part the crop will cut. A photo you frame yourself keeps its own frame. **Enter** crops them all. Re-applying crops from each photo's pre-crop framing rather than the last crop, and the open photo's crop is a normal undo step
- **Export** — Lossless PNG via Rust encoder, JPEG/WebP via browser, **AVIF through a real encoder** (`@jsquash/avif`, a ~3.5 MB wasm chunk fetched on the first AVIF export, never in the initial bundle — the browser silently wrote a PNG before)
- **Blank Canvas** — start a new document from the upload dialog: dimensions + a page-size preset (FHD / Square / Story / 4×6 / 5×7 / 8×10) and a White / Black / hex / **Transparent** background; the fill is generated in Rust (`blank_png` → `codec::export_png`) with no canvas round-trip
- **Create AI Image** — New › Create AI Image turns a prompt into a new photo in your gallery. Pick one of six models from the dropdown: Flux Schnell, Flux Dev, Flux 1.1 Pro, Flux Kontext Pro, Stable Diffusion 3.5 Large or Ideogram v3 Turbo; they differ in speed, cost and whether they can take a reference image. Choose an aspect ratio and, for the three models that read them, attach reference images. The tile shows only with online features on, Generate is a Paid feature checked on the server before anything is sent to Replicate, and the image arrives as an ordinary upload
- **Thumbnails** — 256px WebP thumbnails built from the already-decoded working pixels via Rust `resize_pixels` (uploads decode once, not twice); working canvas stays at ≤2048px
- **Copy/Paste Regions** — Cross-photo pixel compositing with alpha blending; paste from clipboard supported; the placement box moves, resizes and **rotates** about its centre (Shift snaps to 15°) before it commits — nearest-neighbour while dragging, bilinear on commit, and a rotated paste is a "Rotate Layer" history step
- **History** — Undo/redo with labeled snapshots (including dimensions for crop/resize/rotate correctness), jump-to, delete entry. Depth is 50 steps by default and up to 1000 in **Settings → General**. The status bar shows **Undo NN%** — how deep undo can reach right now as a share of that setting
- **Per-photo Edit Persistence** — Switching photos saves the full WASM canvas + undo/redo stack to IndexedDB (PNG-encoded per snapshot). Switching back restores the exact edit session — same canvas state, same undo history, all redo steps intact
- **Layers** — a real layer stack per photo: 8 layers per image, 16 on Pro. Add, rename, hide, reorder, set opacity, delete and flatten from **Review → Layers**; **Edit → Layers** moves, resizes and masks the picked layer (paint the mask, invert it, apply it or remove it) and adds a color overlay. The stack lives in the Rust engine and is saved with the edit, so it survives a reload
- **OpenRaster export and import** — **Settings → Import / Export** writes the full project, every layer, to an `.ora` file that opens in Krita, GIMP and other editors, and opens an `.ora` as a new photo with its layer stack restored
- **Plugins** — features from outside the app, added in **Settings → Plugins** from a file or a link and kept on this device (a master switch, then one per plugin; nothing fetched on the app's own initiative). A format plugin adds its file type to the Download dialog — every format a plugin brings gets its own tile, the layered ones (ORA, PSD) last — and to Import / Export; the **Photoshop PSD** plugin, in its own repository, exports the full project as a layered `.psd` and opens a `.psd` as a new photo with its layers. See [Plugins](Plugins.md)
- **SVG → SVG** — an image uploaded as SVG can be downloaded as SVG again from the Download dialog (Selected Image, or a `.zip` of every SVG from All Images). The file is the uploaded markup with only the root `viewBox`/`width`/`height` changed, so crops (Crop, Batch › Crop) carry over and the drawing stays a vector; painting, filters and text live only in the pixel formats. The SVG tile is disabled until an SVG is open, and an SVG rotated or resized unevenly is refused rather than written wrong (`lib/svgPassthrough.ts`). Session-only for now: after a reload the image stays, as pixels

### UI (React)

- **Fast drags are never dropped** — on the Shapes, Arrows & Shapes and Crop canvases a press is recorded the instant it lands, its moves and release are buffered while the engine answers the hit-test, then replayed in order; a quick second drag commits the first instead of overtaking it. Thirty fast drags in a row land thirty shapes (they used to land 19–24) (`lib/pressQueue.ts`)
- **One header row on every second-step dialog** — New Canvas, Create AI Image, Selected Image and All Images share one header: **‹ Back** on the left, the title centered, **✕** on the right, Back the same 24px button as the close. One close per dialog (`PaneHeader`, a `1fr auto 1fr` grid)
- **Sign in from Settings** — a labeled **Sign in** button on the far right of the Settings footer (your avatar once you are signed in), as well as the person icon in the top bar

- **Animated Panels** — Staggered entrance: TopBar → Sidebar → Gallery (Framer Motion springs)
- **Pan (H or Space)** — **H** is the hand key: hold it and the pan ends on release, tap it and the pan stays on until the next tap or Esc. Holding Space still pans. All tool handlers are bypassed during a pan, and typing `h` in a text field does nothing
- **A/B Compare Slider** — Squoosh-style draggable divider, toggled from the top bar over every tool except Batch; overlay is positioned exactly over the canvas bounding box (tracks zoom/pan via ResizeObserver) so before/after layers are always pixel-aligned
- **Multi-photo Gallery** — Bottom strip with thumbnails, add/remove/switch/**duplicate** (content-addressed, zero-copy; carries edits); PgUp/PgDn cycling; multi-select with Export / Delete / Duplicate / Unselect; header count + per-tier limit `(i)` tooltip; originals preserved in IndexedDB at full resolution regardless of working-copy downscale. A photo still being imported shows a placeholder tile until it is ready, and a slow switch dims the canvas under "Loading <name>" so the numbers on screen never belong to the photo you just left. Download All shows its progress, skips a photo it cannot read, and says how many it skipped. While photos are still loading (a restore or a big import), the gallery goes to placeholders as one piece, in place, like the Tools card during a slow switch: after 300 ms the header and arrows turn to muted blocks of their own size and empty tiles show placeholders, then everything comes back without moving
- **Review Panel** — Right-side panel (Alt+R) with a header toggle group that opens up to three stacked sections sharing the body height (1 full / 2 halves / 3 thirds, each scrollable):
  - **History** — clickable undo/redo timeline with an inline Undo button and a live step count
  - **Reselect** — every committed text and shape annotation as a row; click to re-select it on the canvas, hover the ✕ to delete
  - **Layers** — the photo's layer stack: add, rename, hide, reorder, set opacity, delete, flatten, with the per-tier limit shown
  - **Histogram** — the live RGB / Luma scope
  - **Combine** — how the next region meets the selection you have: **New selection / Add / Subtract / Intersect**, the standing choice for every selection gesture (Shift and Alt still override it for one gesture). Starts closed. Moved here out of the Select panel, and it now applies to placed objects too: the same text-and-shape list Reselect shows, where clicking a row combines the area that object covers — its box, or its ellipse for a circle. The marching ants show the selection on the canvas whatever tool is held
- **Upload** — Drag-and-drop modal with file browser and paste-from-clipboard (Ctrl+V / paste button)
- **Export Dropdown** — PNG, JPEG, WebP, AVIF format selector in the top bar
- **Keyboard Shortcut Modal** — Alt+/ opens a full reference overlay grouped by category (two columns per group)
- **Diagnostics Log** — `Alt+Delete`, or *Toggle Diagnostics* in the command palette, opens a log overlay: engine, IndexedDB, Convex, AI and console entries for the current tab, up to 500 of them, held in memory only — never persisted and never sent anywhere
- **Erasers and AI removal** — three sub-tools over one tool id (`ai`, unchanged for shortcut/persistence/routing). **Create → Eraser**: drag on the canvas to scrub the active layer to transparent — local, free, no sign-in. **Create → Magic Eraser**: paint over something and PatchMatch fills it in, on your machine, free. **Enhance → AI** (Pro, needs the network): Background Removal (rembg) and Object Removal (LaMa), both run on Replicate. The tile opens for everyone, even with online features off: both buttons show with a key badge, and pressing one says what it needs. Nothing is sent while online features are off. Object Removal is a brush on the real canvas — you paint the mask over the object at whatever zoom you are on, with Undo Stroke and Clear Mask, and the mask stays over the object while the job runs
- **Light / Dark / System theme** — full light & dark palettes (warm earth-tone dark, warm-paper light) driven by CSS-variable tokens in `styles.css` (`:root` light, `.dark` dark, `@custom-variant dark`); "System" follows the OS via `matchMedia` and updates live. Pre-paint guard in `index.html` (no FOUC). Set in **Settings → Appearance**, persisted to localStorage + Convex. JetBrains Mono + DM Sans throughout
- **Rulers & Grids** — toggleable top/left pixel rulers (tick labels track zoom) + a configurable non-destructive grid overlay: square px spacing, golden-ratio lines, or N×M divisions, with color + opacity. Set in **Settings → Rulers & Grids**, persisted. The grid-layout geometry is computed in **Rust** (`grid_lines` WASM export) as the single source, projected to an SVG overlay on the canvas
- **State management (Zustand)** — the editor's state lives in seven Zustand stores (UI, tool, gallery, annotation, guides, perspective, text box) instead of `AppShell` local state; components subscribe with atomic selectors for minimal re-renders, and durable prefs (last master-bar tab, tool sub-modes) persist to IndexedDB via a write-deduped `StateStorage` adapter. Behavior-preserving groundwork for splitting `AppShell` into feature modules. See [State Management](archive/State-Management.md)
- **Five-group toolbar** — the rail is five groups (Enhance · Select · Create · Edit · Batch) owning 38 sub-tools, replacing eleven flat tools. One registry (`features/tools/toolGroups.ts`) defines them, and the rail, the sub-tool row, the digits `1`–`5`, the shortcut sheet, the canvas dispatch and the cursor all derive from it — there is no second table to fall out of step. Legacy tool ids are untouched underneath, so persistence and old links keep working
- **Sub-tool routing** — every sub-tool has its own address: `#/create/brush`, `#/edit/color-picker`, `#/select/ellipse`. Thirty-five older URL shapes redirect to the sub-tool they meant, each pinned by a test. The three Edit sub-tools that share a tool underneath used to collapse onto one URL; they no longer do
- **Sub-tool canvas dispatch** — the lit sub-tool decides what a drag does and which cursor you get, instead of the whole parent tool sharing one. A sub-tool with no canvas gesture idles by default rather than inheriting whatever the clone stamp was doing
- **Color picker history** — eyedroppered colors land in a Recent Colors list under **Edit → Color Picker**: click to re-apply to brush and text, ✕ to forget, Clear to empty. Same list UI as the guides list. Per-session, not persisted
- **OCR** — reading text out of an image is its own sub-tool (**Create → OCR**) rather than a mode buried inside the Text panel
- **Shape action bar** — select a rectangle, circle, diamond, star or triangle and a bar hangs under it: **Apply** (Enter) · **Cancel** (Esc) · **Duplicate** · **Connect**. Duplicate opens eight small arrows around the shape, one per bounding-box handle, each pointing away from it; every press lays another same-sized copy that way, `[-] 20px [+]` apart. Each arrow counts on its own from the *original* — → twice gives two marching right, a later ↓ goes below the source — and a turned shape duplicates along its own axes. Connect swaps the arrows for pigtails: drag from one onto another shape and an arrow joins the two, snapped to the nearest of that shape's eight points. Connect is off while Duplicate is on, and a shape too small on screen gets no bar at all — zoom in and it comes back. Replaces the Review → Reselect d-pad and row Duplicate (`lib/shapePorts.ts`, `app/session/useShapeActions.ts`); copies are an engine-side struct clone (`duplicate_shape_annotation`), connectors are ordinary arrow annotations. **Connectors follow**: an arrow joined to a shape stays on the same point of its outline when the shape moves, resizes or turns, and one undo puts both back. **Disconnect** shows a ✕ on each joined end; press it to remove that connector
- **Stroke Stabilizer, everywhere** — the pulled-string "lazy mouse" leash reaches the Paint brush, the Eraser, the blur brush, pixelate, redact and the clone stamp from a single setting. One leash implementation (`src/stabilizer.rs`) with its level table exported to JS as `stabilizer_leash`, so no consumer re-derives the numbers. On the clone stamp the source offset is preserved exactly — a lagging tip samples a source lagging by the same vector — and a move inside the leash costs zero recomposites, because every stroke engine returns whether it actually stamped

- **Settings sync — every tab, every signed-in device** — change a setting in one tab and the others are already right when you switch to them, with no reload and no account: a `BroadcastChannel` carries it across tabs on this device, which is sync a signed-out user gets too. Sign in and the same change reaches your phone and your other computers over one reactive Convex query. Three documents travel — your preferences, the panels/tabs you left open with the command palette's recent list, and which mode each tool was in — replicated whole, with the deciding rule (`adopt` / `push` / `hold` / `idle`) as one pure function that has its own spec, and a server that refuses a write based on a revision someone else has already moved past. **Your photos are not in it**: originals, edits and the gallery stay in the browser that made them, exactly as they do signed out. **Settings → General** shows what sync is doing and can delete the synced copy from your account. See [ADR-061](adr/061-sync-is-a-document-layer-and-the-archive-is-not-in-it.md)
- **Beta features** — **Settings → Beta** lists the unfinished things you can switch on for this browser before they are on for everyone: today the Smart Brush (strokes that stop at an edge) and blur on the graphics card. Each is off until you turn it on, the choice is kept in this browser and never sent anywhere, and **Copy invite link** hands someone else a link (`?beta=<id>`) that turns one on for the device they open it with. `?beta=none` clears them all
- **Share links, and Settings → Shared** — **Export → Share link** uploads a flattened PNG and copies a public link that works for anyone, signed in or not. It needs online features on: with "Everything in your browser" set, the button says why it can't make one and nothing is uploaded. **Settings → Shared** lists every link you have made: its image, how many times it was opened, when it was last opened, and a bar for each of the last 30 days, with your totals on top. Each link can **stop after a number of views**, **stop on a date**, or both; hitting a limit pauses it and keeps the image, so raising the limit turns it back on. Pause, resume and delete by hand too. A stopped link tells the visitor why and sends no image. Each opening is stored as a time only — no address, no browser, no account
