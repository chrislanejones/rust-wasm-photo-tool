### #131 — fonts: the design question is ANSWERED, the work is mechanical

**Do not ask for a decision here again.** `docs/fonts-131-decision.md` §3 was
rewritten 09-17 (PR #166, merged) and now answers it by measurement.

The old framing was wrong twice, and the doc says so rather than quietly
changing its mind:

- **"Runtime or embedded" is a false choice.** `src/text.rs:13-14` on master
  already compiles two Liberation Sans faces in. #131 keeps the **byte-identical
  blobs**. Embedding is the status quo.
- **The PR's title and its sentinel edit never disagreed.** It does *both*:
  embedded pair as the baseline, plus runtime registration for four more faces.
  Its ~999 added lines of Rust put **zero** new font bytes in the wasm.

| | Bytes |
|---|---|
| Live engine (sentinel PASS 09-17) | **845,156** |
| Font data already inside it | **123,492** = **14.6%** |
| Ceiling | 860,000 |
| Headroom | 14,844 |
| Floor (featureless-build detector, **stays**) | 800,000 |
| #131 asks for | 872,000 (**+12,000** over today) |

**The finding that changes the arithmetic.** The embedded and shipped copies of
the same face are different builds:

| | Embedded | Shipped |
|---|---|---|
| Size | 61,972 | **29,748** |
| Glyphs | 460 | **458** |
| Hinting (`fpgm`/`prep`) | present | **absent** |

The engine rasterizes with `ab_glyph`, which **never executes TrueType hinting
bytecode**. So ~**64,000 bytes** of the embedded pair is instruction data
nothing runs — four times the current headroom, five times what #131 asks for.
Swapping to the unhinted build would likely let #131 land with **no ceiling
move at all**.

⚠️ **Two things deliberately unverified**: the branch was never built, so
#131's real wasm size is unmeasured; and the unhinted swap needs a **pixel**
check, since the comparison above is of font tables and glyph counts, not
rendered output.

**Recommendation: hybrid + unhinted swap in the same commit.** Remaining work
is mechanical: renumber its ADR to **057** (master has a different ADR-053 from
#130), merge master in and resolve four Rust files plus the
`engineAsyncMigration` counter, then measure before touching the ceiling.

## 5. Two traps this session hit, worth not re-learning

**Plan premises go stale fast.** The late-night plan listed three things for
"tonight" that were **all already done** before it was pasted — #160 merged,
the audit written, the fonts decision written. That is the eighth plan in a row
to arrive with its stop condition already met. Check premises against the repo
before working.

**Ports: this machine refuses low ports with nothing listening.** A whole range
(4319, 4321, 4327, 3000-3010, 8080-8100, 9200-9220) returned `EADDRINUSE` while
`ss -ltnp` showed nothing bound. Binding to port **0** and taking whatever the
OS gives works. Do not burn time hunting a "free" low port.
