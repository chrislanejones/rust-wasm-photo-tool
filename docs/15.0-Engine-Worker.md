# 15. The Engine Worker

[← 14. The AppShell Refactor](14-AppShell-Refactor.md) · [Contents](README.md) · [15.1 Feasibility →](15.1-Engine-Worker-Feasibility.md)

The image engine (the Rust/WASM `stamp_tool`) runs in a **web worker**, not on
the page's main thread. A heavy edit used to block the page for 129–137 ms;
with the engine in its worker, the main thread is blocked for **0 ms**. The
worker has been the default since **v8.32**
([ADR-024](adr/024-engine-in-a-worker.md)).

The worker also owns the canvas: the page hands its `OffscreenCanvas` to the
engine's worker, which draws the finished picture straight into it. The codec
worker (encoding, thumbnails) is a separate worker and loads no engine.
`ih_engine_worker=0` in localStorage puts the engine back on the main thread,
the kill switch.
